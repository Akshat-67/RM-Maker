# Project Engineering Policy

- Automated tests are first-class project assets.
- Production code changes require reviewing and updating relevant tests.
- Every bug fix requires a regression test.
- New features require new automated coverage.
- Before declaring a task complete, run relevant tests and report results.
- Architectural decisions should be persisted as Serena memories.
- Architecture documentation should remain synchronized with the implementation.


# Project Completion Policy

When completing significant work:

- verify implementation
- verify tests
- verify documentation
- verify memories
- verify architecture consistency

Do not consider implementation alone sufficient.
